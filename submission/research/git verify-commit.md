# Git Verify-commit

## إيه هو `git verify-commit`؟

بستخدم الأمر ده علشان أتأكد إن الـ `Commit` عليها توقيع رقمي صحيح، وإن محتواها متغيّرش بعد ما اتوقّعت.

التوقيع الرقمي بيساعدني أتحقق إن صاحب المفتاح اللي اتعمل بيه التوقيع هو اللي وقّع الـ `Commit`. لكن علشان أتأكد من هوية الشخص نفسه، لازم أكون واثق من إن المفتاح العام فعلًا بتاعه.

## إزاي بستخدمه؟

لو عاوز أتحقق من آخر `Commit`، بكتب:

```bash
git verify-commit HEAD
```

ولو عاوز أتحقق من `Commit` معينة، بحط رقمها بدل `HEAD`:

```bash
git verify-commit a1b2c3d
```

لو التوقيع صحيح والمفتاح العام متاح عندي، Git هيعرض معلومات عن التوقيع وصاحبه. ولو الـ `Commit` مش متوقّعة، أو المفتاح مش متاح، أو التحقق فشل، هيظهرلي سبب المشكلة.

## مثال بسيط

لنفترض إني استلمت تعديل مهم وعاوز أراجع توقيع الـ `Commit` قبل ما أعتمد عليه. أول حاجة بجيب رقمها:

```bash
git log --oneline -1
```

بعدها بتحقق منها:

```bash
git verify-commit HEAD
```

لو التحقق نجح، أعرف إن التوقيع متوافق مع محتوى الـ `Commit`. ولو عاوز أشوف التعديل نفسه كمان، أستخدم:

```bash
git show HEAD
```
