# Git Grep

## إيه هو `git grep`؟

أمر `git grep` بستخدمه علشان أدوّر على كلمة أو جزء من الكود جوه ملفات المشروع.

بدل ما أفتح كل ملف وأدوّر فيه بنفسي، أقدر أكتب أمر واحد يوضحلي الكلمة موجودة في أنهي ملف وفي السطر رقم كام.

لازم أشغّل الأمر وأنا واقف جوه مشروع Git.

## طريقة استخدامه

```bash
git grep "الكلمة اللي بدوّر عليها"
```

## مثال عملي

لنفترض إن عندي مشروع Laravel، وعاوز أعرف الدالة `sendEmail` مستخدمة فين جوه المشروع.

هكتب الأمر ده:

```bash
git grep "sendEmail"
```

ممكن تظهرلي النتيجة بالشكل ده:

```text
app/Services/OrderService.php:sendEmail($order);
app/Jobs/SendInvoice.php:sendEmail($invoice);
```

النتيجة دي معناها إن `sendEmail` موجودة في ملفين:

* `OrderService.php`
* `SendInvoice.php`

فبدل ما أفتح ملفات المشروع واحد واحد، الأمر وصلني مباشرةً لكل الأماكن اللي اتستخدمت فيها الدالة.

## إظهار رقم السطر

لو عاوز أعرف رقم السطر اللي الكلمة موجودة فيه، بضيف `-n`:

```bash
git grep -n "sendEmail"
```

ممكن تكون النتيجة كده:

```text
app/Services/OrderService.php:25:sendEmail($order);
app/Jobs/SendInvoice.php:40:sendEmail($invoice);
```

الرقم `25` معناه إن الكلمة موجودة في السطر رقم 25، والرقم `40` معناه إنها موجودة في السطر رقم 40.

## البحث من غير ما أفرّق بين الحروف الكبيرة والصغيرة

ممكن نفس الكلمة تكون مكتوبة بأكتر من شكل:

```text
payment
Payment
PAYMENT
```

لو عاوز أبحث عن كل الأشكال دي، بستخدم `-i`:

```bash
git grep -i "payment"
```

كده Git هيدوّر على الكلمة من غير ما يفرق بين الحروف الكبيرة والصغيرة.

## البحث جوه نوع معين من الملفات

لو عاوز أبحث جوه ملفات PHP بس، أكتب:

```bash
git grep "sendEmail" -- "*.php"
```

الجزء ده:

```bash
-- "*.php"
```

معناه إن البحث هيكون جوه الملفات اللي امتدادها `.php` بس.

## الخلاصة

`git grep` هو أمر بيساعدني أدوّر بسرعة على كلمة أو دالة أو متغير جوه ملفات المشروع.

أكتر شكل عملي للأمر هو:

```bash
git grep -n "النص المطلوب"
```

* `git grep` بيعمل عملية البحث.
* `-n` بيعرض رقم السطر.
* النص اللي بين علامتي التنصيص هو النص اللي بدوّر عليه.

الأمر ده مفيد جدًا في المشاريع الكبيرة، خصوصًا لما أكون عاوز أعرف كل الأماكن اللي اتستخدمت فيها دالة أو متغير معين، بدل ما أفتح ملفات المشروع وأدوّر فيها واحد واحد.
