# Git Clean

## إيه هو `git clean`؟

أمر `git clean` بستخدمه علشان أمسح الملفات الجديدة اللي Git لسه مش بيتابعها، واللي بتظهر في `git status` تحت:

```text
Untracked files
```

يعني لو عملت ملفات للتجربة ولسه مضيفتهاش باستخدام `git add`، الأمر يقدر ينضّفها من المشروع.

## إزاي أراجع الملفات قبل الحذف؟

قبل ما أمسح أي حاجة، بستخدم:

```bash
git clean -n
```

الأمر ده بيعرض الملفات اللي هتتمسح من غير ما يمسحها فعلًا.

## حذف الملفات

بعد ما أراجع النتيجة وأتأكد، بستخدم:

```bash
git clean -f
```

الاختيار `-f` معناه تنفيذ الحذف بالقوة.

## حذف الملفات والفولدرات

لو عاوز أمسح الملفات والفولدرات الجديدة:

```bash
git clean -fd
```

ولمعاينة النتيجة الأول من غير حذف:

```bash
git clean -nd
```

## الحذف بطريقة تفاعلية

ممكن أختار بنفسي الملفات اللي عاوز أمسحها:

```bash
git clean -i
```

Git هيعرض الملفات ويسألني قبل تنفيذ الحذف.

## الملفات الموجودة في `.gitignore`

بشكل طبيعي، `git clean` مش بيمسح الملفات الموجودة في `.gitignore`.

لو عاوز أمسحها كمان:

```bash
git clean -fdx
```
