# Git Blame

## إيه هو `git blame`؟

أمر `git blame` بستخدمه علشان أعرف آخر شخص عدّل كل سطر في ملف معين، والتعديل ده كان موجود في أنهي `Commit`.

الأمر ده بيكون مفيد جدًا لما ألاقي سطر في الكود وعاوز أفهم:

* مين آخر شخص عدّله؟
* اتعدل إمتى؟
* موجود في أنهي `Commit`؟
* إيه التغييرات التانية اللي حصلت معاه؟

لازم أشغّل الأمر وأنا واقف جوه مشروع Git.

## طريقة استخدامه

```bash
git blame path/to/file
```

بكتب `git blame` وبعده مسار الملف اللي عاوز أشوف تفاصيل الأسطر بتاعته.

## مثال عملي

لنفترض إن عندي ملف في مشروع Laravel اسمه:

```text
app/Services/OrderService.php
```

وعاوز أعرف مين عدّل الأسطر الموجودة فيه، هكتب:

```bash
git blame app/Services/OrderService.php
```

ممكن تظهر النتيجة بالشكل ده:

```text
a8c31fd2 (Ahmed 2026-09-01 10:30:00 +0300 20) public function createOrder()
b71e92ab (Yousef 2026-09-05 02:10:00 +0300 21) {
b71e92ab (Yousef 2026-09-05 02:10:00 +0300 22)     return Order::create($data);
b71e92ab (Yousef 2026-09-05 02:10:00 +0300 23) }
```

## إزاي أقرأ النتيجة؟

ناخد السطر ده كمثال:

```text
b71e92ab (Yousef 2026-09-05 02:10:00 +0300 22) return Order::create($data);
```

السطر ده فيه كذا معلومة:

* `b71e92ab` هو رقم الـ `Commit` اللي حصل فيه آخر تعديل على السطر.
* `Yousef` هو اسم الشخص اللي عمل التعديل.
* `2026-09-05` هو تاريخ التعديل.
* `22` هو رقم السطر في الملف.
* `return Order::create($data);` هو محتوى السطر نفسه.

يعني من النتيجة دي عرفت إن آخر شخص عدّل السطر رقم 22 هو `Yousef`، وإن التعديل موجود في الـ `Commit` اللي رقمه `b71e92ab`.

## عرض جزء معين من الملف

مش لازم أعرض كل أسطر الملف. لو عاوز أشوف الأسطر من رقم 20 لحد رقم 25 بس، أستخدم `-L`:

```bash
git blame -L 20,25 app/Services/OrderService.php
```

الرقم `20` هو أول سطر، والرقم `25` هو آخر سطر عاوز أعرضه.

الطريقة دي مفيدة لو الملف كبير وأنا مهتم بجزء صغير منه بس.

## معرفة تفاصيل الـ Commit

بعد ما استخدمت `git blame` وعرفت رقم الـ `Commit`:

```text
b71e92ab
```

أقدر أشوف تفاصيله باستخدام:

```bash
git show b71e92ab
```

الأمر ده هيعرضلي:

* صاحب الـ `Commit`.
* تاريخ التعديل.
* رسالة الـ `Commit`.
* الملفات اللي اتعدلت.
* الأسطر اللي اتمسحت أو اتضافت.

بكده `git blame` وصلني للـ `Commit`، وبعدها `git show` ساعدني أفهم التعديل بشكل كامل.

## مثال على مشكلة حقيقية

لنفترض إن عندي الشرط ده في المشروع:

```php
if ($order->status === 'cancelled') {
    throw new Exception('Order cannot be updated');
}
```

وأنا مش عارف الشرط ده اتضاف ليه أو مين عدّله.

لو الشرط موجود من السطر 45 لحد السطر 47، أكتب:

```bash
git blame -L 45,47 app/Services/OrderService.php
```

ممكن تظهر النتيجة:

```text
91ce45ab (Ahmed 2026-08-20 12:15:00 +0300 45) if ($order->status === 'cancelled') {
91ce45ab (Ahmed 2026-08-20 12:15:00 +0300 46)     throw new Exception('Order cannot be updated');
91ce45ab (Ahmed 2026-08-20 12:15:00 +0300 47) }
```

كده عرفت إن الأسطر دي آخر تعديل عليها كان في الـ `Commit` رقم:

```text
91ce45ab
```

بعد كده أستخدم:

```bash
git show 91ce45ab
```

علشان أشوف باقي التغييرات ورسالة الـ `Commit`، وممكن من خلالها أفهم سبب إضافة الشرط.

## ملاحظة مهمة

`git blame` بيعرض آخر شخص عدّل السطر، مش شرط يكون هو أول شخص كتبه.

يعني ممكن شخص يكون كتب السطر من البداية، وبعد فترة شخص تاني عمل تعديل بسيط عليه. في الحالة دي `git blame` هيعرض اسم آخر شخص عدّل السطر.


## الخلاصة

`git blame` بيساعدني أعرف تاريخ كل سطر في الملف، وآخر شخص عدّله، والـ `Commit` اللي حصل فيه التعديل.

أهم الأوامر اللي ممكن أستخدمها:

```bash
git blame path/to/file
```

لعرض تفاصيل كل أسطر الملف.

```bash
git blame -L 20,25 path/to/file
```

لعرض تفاصيل أسطر معينة.

```bash
git show commit_id
```

لعرض تفاصيل الـ `Commit` بعد ما أجيب رقمه من نتيجة `git blame`.

الأمر ده مفيد جدًا لما ألاقي جزء قديم أو غير واضح في الكود، وعاوز أعرف تاريخ التعديل وأفهم السبب اللي خلّى الجزء ده يتكتب بالشكل ده.
