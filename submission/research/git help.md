# Git Help

## إيه هو `git help`؟

أمر `git help` بستخدمه لما أكون عاوز أعرف شرح أمر معين في Git وطريقة استخدامه والاختيارات المتاحة فيه.

بدل ما أبحث على الإنترنت، أقدر أجيب التوثيق الخاص بالأمر من Git نفسه.

## طريقة استخدامه

لو عاوز أشوف المساعدة العامة الخاصة بـ Git، أكتب:

```bash
git help
```

الأمر ده بيعرض مجموعة من أشهر أوامر Git، زي:

```text
clone
init
add
commit
status
branch
```

## معرفة تفاصيل أمر معين

لو عاوز أعرف تفاصيل أمر `commit`، أكتب:

```bash
git help commit
```

هيظهر شرح كامل للأمر، وطريقة استخدامه، والاختيارات المتاحة معاه.

ممكن أستخدم نفس الطريقة مع أي أمر تاني:

```bash
git help add
```

```bash
git help branch
```

```bash
git help merge
```

## المساعدة المختصرة

لو محتاج أشوف أهم الاختيارات بسرعة من غير ما أفتح الشرح الكامل، أستخدم `-h`:

```bash
git commit -h
```

أو:

```bash
git add -h
```

الاختيار `-h` بيديني ملخص سريع داخل الـ Terminal، لكن `git help` بيفتح شرح أكثر تفصيلًا.

## مثال بسيط

لو نسيت الاختيار المستخدم لتعديل آخر Commit، أقدر أكتب:

```bash
git commit -h
```

وهلاقي ضمن الاختيارات:

```text
--amend
```

بعدها أقدر أستخدمه بالشكل ده:

```bash
git commit --amend
```

## الخلاصة

`git help` بيساعدني أفهم أوامر Git من التوثيق الخاص بيها.

للحصول على شرح كامل لأمر معين:

```bash
git help command-name
```

ولعرض مساعدة سريعة:

```bash
git command-name -h
```

الأمر ده مفيد لما أنسى طريقة استخدام أمر أو اختيار معين، وعاوز أوصل للمعلومة بسرعة.
